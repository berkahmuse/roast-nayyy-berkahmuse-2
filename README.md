## The roast

> Our agent needs five approval taps, three subagents and a fresh drand beacon to write one roast — then calls the delay 'sat set'.

## How it works

`main.ts` writes that single line to `/output/entry.txt` — nothing else. No network, no secrets, no environment reads: the whole entry is the program in this repository.

## Run it

```sh
node main.ts   # Node 22.18+
cat /output/entry.txt
```
